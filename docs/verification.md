# Проверка версии 1.0

Среда: JDK 21, Gradle 9.4.1, Android SDK 36.1. Устройство: Medium_Phone, эмулятор Android 15 / API 35.

- `assembleDebug` — APK собран.
- `testDebugUnitTest` — три теста расчётов: точность копеек и некорректный ввод, границы месяца, баланс счетов и будущие операции.
- `lintDebug` — без ошибок; предупреждения о доступности новых версий SDK/зависимостей и рекомендациях KTX не блокируют сборку.
- `FinanceDatabaseTest` — два инструментальных теста: добавление/редактирование/удаление и повторное открытие SQLite; восстановление копии и отклонение некорректного файла без потери текущих данных.
- `FinanceFlowTest` — один сквозной тест: загрузка демопримера, четыре раздела, добавление расхода, поиск, пересоздание Activity и редактирование суммы.
- Визуально проверены реальные экраны обзора, операций, аналитики, бюджетов и ввода. Их снимки находятся в `screenshots/`.

Результаты проверки: `BUILD SUCCESSFUL`; 3 модульных теста и 3 инструментальных теста прошли. Дополнительный прогон UI-теста также завершился успешно. Машинные логи сохранены локально и исключены из Git.

Ручной выбор места сохранения CSV/JSON через системный файловый менеджер не автоматизирован UI-тестом. Сам JSON round-trip и некорректный импорт покрыты инструментальными тестами. Проверка на физических телефонах и других версиях Android не выполнялась.
